# adr

## 쓸지 판단

- 쓴다 - 되돌리기 어렵고 제품 구조에 영향
- 안 쓴다 - 쉽게 바꿀 수 있는 것
- 애매하면 사용자에게 확인

## 작성

- 기존 ADR을 참고하되 결정에 맞게 섹션 조정
- 결정과 이유가 먼저 보이게
- 파일명 `NNNN-<영문-kebab>.md`, 번호는 기존 최대값 + 1
- 초안을 사용자에게 보여주고 확인 후 저장
