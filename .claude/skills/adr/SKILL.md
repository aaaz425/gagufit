# adr

## 쓸지 판단

- 쓴다 - 되돌리기 어렵고 제품 구조에 영향 (저장 구조, 패키지 경계, 외부 서비스 선택 등)
- 안 쓴다 - 쉽게 바꿀 수 있는 것 (라이브러리 세부 설정, 개발 도구, 하네스)
- 애매하면 사용자에게 확인

## 작성

- 형식은 `docs/adr/0001-monorepo-and-mobile-web.md` 그대로 - 결정, 근거, 대안(표), 트레이드오프
- 파일명 `NNNN-<영문-kebab>.md`, 번호는 기존 최대값 + 1
- 결정을 맨 앞에, 근거는 한 줄씩
- 대안 표에는 실제로 검토한 것만, 결정에서 자동으로 따라오는 것은 제외
- 초안을 사용자에게 보여주고 확인 후 저장
