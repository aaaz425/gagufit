# 유저 플로우

1차 기준 - 로그인 없이 시작해 같은 브라우저에서 이어보기

## 전체

```
랜딩 → 시작하기 → 방 템플릿 선택 → 편집기 ⟲ 자동 저장
  ↑                                    |
  └──── 재방문 - 내 방 목록에서 열기 ────┘
```

## 첫 방문

- 랜딩 - 서비스 소개, 시작하기 버튼
- 시작하기 - 익명 로그인 자동 처리, 사용자에게 안 보임
- 방 템플릿 선택
  - 원룸 템플릿 몇 개 + 빈 방
  - 고른 뒤 가로·세로·층고 수정 가능
- 편집기 진입 - 방 이름 기본값 자동 부여

## 편집

- 방 - 치수 수정, 문·창문 배치
- 가구 - 목록에서 추가 → 이동·회전·삭제
- 경고 - 겹침·벽 밖 이탈 시 해당 가구 표시, 막지는 않음
- 보기 - 2D 탑뷰 ↔ 3D 전환
- 품질 설정 - 저사양이면 끄기

## 저장

- 변경 시 자동 저장, 저장 버튼 없음
- 상태 표시 - 저장 중·저장됨·실패
- 실패 시 재시도, 다시 실패하면 안내

## 재방문

- 같은 브라우저 - 랜딩에 내 방 목록
  - 방 열기, 새 방 만들기, 이름 변경, 삭제
- 다른 기기 - 1차 불가, 2차 카카오 로그인으로 연결

## 예외

- 로그인 정보 소실 시 방 접근 불가 - 내 방 목록·편집기에 미리 안내
  - 브라우저 데이터 삭제, 시크릿 창, 다른 브라우저
- WebGL 미지원 - 2D 탑뷰만 사용
- 프레임 저하 - 품질 설정 끄기 제안

## 2차 이어질 자리

- 카카오 로그인 - 내 방 목록에 "다른 기기에서 보기" 진입점
- 공유 보기 - 편집기에서 링크 생성 → 받은 사람은 읽기 전용
- 견적·쿠팡 링크 - 편집기 가구 상세
