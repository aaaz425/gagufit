# 화면 구성

1차 기준 - 랜딩·내 방 목록·편집기·설정·약관, 2차 계정 자리 미리 확보

## 화면 목록

| 화면        | 경로                 | 내용                                  |
| ----------- | -------------------- | ------------------------------------- |
| 랜딩        | `/`                  | 소개, 시작하기                        |
| 내 방 목록  | `/rooms`             | 방 카드 목록, 새 방 만들기            |
| 템플릿 선택 | 내 방 목록 위 모달   | 원룸 템플릿 + 빈 방, 치수 수정        |
| 편집기      | `/rooms/[id]`        | 방·문·창문·가구 편집                  |
| 약관        | `/terms`, `/privacy` | 이용약관, 개인정보처리방침            |
| 설정        | `/settings`          | 화면 품질, 서비스 소개·약관, 2차 계정 |
| 로그인      | 모달                 | 2차 - 카카오로 계속하기               |
| 공유 보기   | `/share/[id]`        | 2차 - 편집기 읽기 전용                |

- 랜딩은 소개 전용, 내 방 목록은 앱 첫 화면 - 성격 분리
- 재방문자 자동 이동 없음 - 랜딩 상단 내 방 버튼으로 한 번에 이동
- 랜딩 가는 길 - 로고, 설정·푸터의 서비스 소개
- 회원가입 화면 없음 - 카카오 로그인이 곧 가입, 익명으로 만든 방 그대로 연결
- 템플릿 선택은 별도 화면 없이 모달 - 단계 하나 줄임
- 없는 방·남의 방 id - 편집기 자리에 안내 + 내 방 목록 링크

## 랜딩

- 상단 내비 - 로고 + `방 만들기 | 내 방 | 설정 | 로그인` 글자 링크, 현재 화면 굵게
  - 방 만들기 - 내 방 목록으로 이동 + 템플릿 선택 열림
- 첫 화면 - 한 줄 소개, 시작하기, 편집기 미리보기 이미지
- 사용 방법 - 3단계
- 기능 소개 - 실제 치수, 겹침 알림, 2D·3D, 로그인 없이 저장
- 푸터 - 약관 링크

## 내 방 목록

- 상단 내비 - 랜딩과 같음
- 새 방 만들기 - 목록 첫 칸 카드, 모바일은 목록 위 한 줄
- 카드 - 이름, 탑뷰 썸네일, 수정일
  - 메뉴 - 이름 변경, 삭제
- 빈 목록 - 템플릿 선택 바로 열림
- 브라우저 저장 안내 한 줄
- 2차 - 다른 기기에서 보기(카카오) 진입점
- 푸터 - 서비스 소개, 약관

## 설정

- 계정 2차 - 로그인 전 카카오로 로그인, 로그인 후 프로필·로그아웃·회원 탈퇴
- 화면 품질 - 고해상도·그림자·후처리 켜기·끄기, 편집기 설정과 같은 값
- 정보 - 서비스 소개, 이용약관, 개인정보처리방침, 버전
- 브라우저 저장 안내

## 계정

- 상단 내비 `로그인` 자리 - 1차 숨김, 2차 로그인 모달 열기, 로그인 후 숨김
- 내 정보 화면 따로 없음 - 설정 계정 영역에서 처리
- 로그인 모달 2차 - 지금 방이 이어진다는 안내, 카카오로 계속하기, 나중에

## 편집기 구성 요소

- 상단 바 - 내 방 목록으로, 방 이름, 저장 상태, 실행 취소·다시 실행, 경고, 2D·3D 전환, 설정
- 캔버스 - 화면 대부분, 2D 탑뷰로 시작
- 가구 패널 - 카테고리별 목록, 누르면 방 중앙에 추가
- 방 패널 - 가로·세로·층고, 문·창문 목록·추가, 바닥·벽 재질
- 선택 툴바 - 선택한 대상 근처, 90° 회전·복제·삭제
- 회전 핸들 - 선택한 가구에 표시, 끌어서 자유 회전, 0·90·180·270° 근처에서 스냅
- 속성 패널 - 선택한 대상의 이름·치수·회전값 직접 입력, 가구 색
  - 2차 - 참고가·쿠팡 링크·대가성 문구 자리
- 경고 - 해당 가구 빨간 외곽선, 상단에 경고 개수
- 러그 - 바닥에 까는 가구, 다른 가구와 겹쳐도 경고 없음
- 설정 - 상단 바 설정 버튼 → 작은 창, 품질(DPR·그림자·후처리) 토글 + 전체 설정 링크

## 실행 취소

- 대상 - 가구·문·창문 추가·이동·회전·크기·삭제, 방 크기·이름
- 제외 - 선택, 2D·3D 전환, 화면 이동·확대, 품질 설정
- 단축키 - ⌘Z·⇧⌘Z, Windows Ctrl+Z·Ctrl+Shift+Z
- 끌기 한 번은 한 단계, 숫자 입력은 입력을 마칠 때 한 단계
- 최대 50단계, 방을 다시 열면 비움
- 되돌릴 것이 없으면 버튼 `ink-subtle` 비활성
- 삭제하면 토스트 "삭제했어요 · 실행 취소"

## 문·창문

- 추가 - 방 패널 `+ 문`·`+ 창문`, 가장 긴 빈 벽 가운데에 놓이고 바로 선택
- 이동 - 끌면 벽을 따라 이동, 다른 벽 가까이 가면 그 벽에 붙음, 모서리 못 넘음
- 폭 - 양끝 핸들로 조절, 속성에서 직접 입력
- 위치 - 방 안에서 벽을 볼 때 왼쪽 끝부터 거리(cm), 드래그 중 가이드
- 방 크기를 줄여 벽보다 길어지면 벽 길이에 맞춰 줄임
- 여닫이 문
  - 열림 영역 부채꼴 표시 - 선택 시 `primary`, 평소 `ink-muted` 옅게
  - 방 안쪽으로 열리고 가구가 영역에 걸치면 경고 - 문 막힘
  - 경첩 왼쪽·오른쪽, 방 안쪽·바깥쪽 선택
- 미닫이 문 - 열림 영역 없음, 두 짝 선으로 표시
- 창문 - 벽 위 얇은 선, 바닥에서 높이·창 높이는 3D용
- 기본값(cm)

| 종류      | 폭  | 높이 | 바닥에서 |
| --------- | --- | ---- | -------- |
| 여닫이 문 | 80  | 200  | 0        |
| 미닫이 문 | 120 | 200  | 0        |
| 창문      | 100 | 120  | 90       |

## 편집기 상태

- 로딩 - 방 모양 자리 + "방을 불러오는 중", 3D는 2D 먼저 보여준 뒤 준비
- 빈 방 - 방 위에 안내 카드 "아직 가구가 없어요" + 가구 추가
- 기본 - 선택 없음
- 선택 - 선택 툴바·회전 핸들·속성 패널 표시
- 드래그 - 이동 중 치수 가이드 표시
- 문·창문 선택 - 폭 핸들·위치 가이드, 여닫이는 열림 영역 강조
- 경고 - 겹침·벽 밖 이탈·문 막힘, 편집은 그대로
- 저장 실패 - 상단 바 `저장 실패` + 토스트 다시 시도, 편집은 계속, 성공하면 둘 다 사라짐
- WebGL 없음 - 3D 전환 비활성, 누르면 이유 한 줄 안내

## 목록·공통 상태

- 없는 방 - "방을 찾을 수 없어요" + 이유 한 줄 + 내 방 목록으로
- 방 카드 메뉴 - 이름 변경, 복제, 삭제
- 삭제 확인 - 모달, 방 이름과 되돌릴 수 없음 안내, `danger` 버튼
- 이름 변경 - 카드·편집기 방 이름 자리에서 바로 입력, 최대 20자
  - Enter·바깥 누르면 저장, Esc 취소, 빈 이름이면 이전 이름 유지

## 데스크톱 배치

```
┌──────────────────────────────────────────────┐
│ ← 내 방   방 이름   저장됨     [2D|3D]  ⚙    │
├──────────┬──────────────────────┬────────────┤
│ [가구|방] │                      │ 속성       │
│          │       캔버스          │ (선택 시)  │
│ 목록     │     [선택 툴바]       │            │
│          │                      │            │
└──────────┴──────────────────────┴────────────┘
```

- 왼쪽 패널 - 가구·방 탭, 접기 가능
- 오른쪽 속성 패널 - 선택 시에만 열림
- 가구 이동 - 바로 드래그

## 모바일 배치

```
┌──────────────────┐
│ ←  방 이름  ✓  ⚙ │
│                  │
│                  │
│      캔버스       │
│   [선택 툴바]     │
│                  │
├──────────────────┤
│ 가구  방  [2D|3D] │
└──────────────────┘
```

- 하단 탭 - 누르면 바텀시트로 패널 열림
- 선택 시 하단 탭 자리에 속성 요약, 위로 끌거나 치수 버튼 누르면 전체 속성 시트
  - 전체 속성 - 크기·위치·각도 입력, 90° 버튼, 복제·삭제, 접기 버튼
- 캔버스 조작
  - 가구 탭 - 선택
  - 가구 길게 누른 뒤 끌기 - 이동, 실수 이동 방지
  - 빈 곳 한 손가락 - 화면 이동
  - 두 손가락 - 확대·회전
- 정밀 조작 - 속성에서 치수·각도 직접 입력
