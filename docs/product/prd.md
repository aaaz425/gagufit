# gagufit PRD

## 목표

- 원룸에 가구가 들어가는지 사기 전에 3D로 확인
- 배치한 가구를 쿠팡 구매로 연결해 제휴 수익

## 대상 사용자

- 원룸 이사·자취 준비 중인 사람
- 가구 크기가 방에 맞는지, 동선이 나오는지 궁금한 사람

## 지원 기기

- 데스크톱·모바일 웹 1차부터 동일 기능 - 3D 편집, 정밀 조작 포함
- 앱은 모바일 웹을 WebView로 그대로 사용

## 기능 범위

### 1차

- 방 만들기 - 가로·세로·층고 입력, 원룸 템플릿에서 시작
- 문·창문 배치
- 가구 배치 - 표준 규격 가구 추가·이동·회전·삭제
- 겹침·벽 밖 이탈 경고
- 2D 탑뷰 ↔ 3D 전환
- 저사양용 품질 설정 끄기
- 로그인 없이 자동 저장, 내 방 목록

### 2차

- 실제 상품 + 쿠팡 링크
- 견적 - 배치한 가구 가격 합계
- 공유 보기
- 카카오 로그인 - 다른 기기에서 내 방 이어보기
- 사용자 상품 제보
- ㄱ자 등 다각형 방
- 치수 직접 입력 가구

## 화면

| 화면      | 단계 | 내용                                |
| --------- | ---- | ----------------------------------- |
| 랜딩      | 1차  | 서비스 소개, 시작하기, 내 방 목록   |
| 편집기    | 1차  | 방·문·창문·가구 편집                |
| 약관      | 1차  | 개인정보처리방침, 이용약관          |
| 공유 보기 | 2차  | 링크로 받은 방을 읽기 전용으로 보기 |

## 출시 기준

- 1차 기능 gagufit.com 배포
- 쿠팡 파트너스 가입 신청 가능한 상태
  - 랜딩에 서비스 소개 콘텐츠
  - 약관 페이지
  - 쿠팡 링크 자리 옆 대가성 문구 위치 확보
- 쿠팡 링크는 가입 승인 후 2차에서 추가
