# 쿠팡 파트너스 신청 점검표

신청 전 사이트 준비 상태 확인용 - 출시 기준은 [PRD](prd.md#출시-기준)

## 사이트

- [x] 서비스 소개 콘텐츠 - 랜딩(`/`)의 소개·사용 방법·기능 구간
- [x] 이용약관(`/terms`), 개인정보처리방침(`/privacy`) - 운영자·연락처·시행일 기재
- [x] 대가성 문구 - 모든 사이트 화면 푸터에 상시 표시
- [ ] 쿠팡 링크 옆 대가성 문구 - 2차에서 링크 추가할 때 링크 바로 옆에 배치
- [x] 연락처 - 약관·처리방침에 운영자 이메일 기재
- [ ] 접속 가능 - 배포 후 도메인(gagufit.com)에서 랜딩·약관 열림 확인
- [ ] 색인 - 배포 후 `/robots.txt`, `/sitemap.xml` 응답 확인

- [ ] 운영자가 쿠팡 파트너스에 직접 신청
