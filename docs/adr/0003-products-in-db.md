# 0003 상품은 DB, 가구는 코드

2026-11-23 확정

## 결정

- 상품은 DB `products`, 기본 가구는 코드
- 배치한 상품은 기본 가구 id + 상품 id·이름으로 저장
- 링크·가격은 방에 안 넣음 - DB에서 조회

## 근거

- 가격·링크는 자주 바뀜 - 고칠 때마다 배포할 수 없음
- 기본 가구는 거의 안 바뀜
- 방을 그릴 때 상품 목록이 필요 없음 - 로딩 없이 열림

## 대안

| 대안                 | 기각 이유                 |
| -------------------- | ------------------------- |
| 기본 가구도 DB       | 방 열기 전 가구 목록 로딩 |
| `presetId`에 상품 id | 방 열기 전 상품 목록 로딩 |
| 가격까지 방에 저장   | 방마다 가격이 낡음        |

## 트레이드오프

- 기본 가구 id는 못 바꿈 - 방과 상품이 함께 씀
- 기본 가구 수정은 배포 필요 - 관리자 페이지·API 분리 시 DB 이전 검토
