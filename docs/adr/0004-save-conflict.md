# 0004 저장 충돌 감지

2026-11-23 확정

## 결정

- 저장할 때 `updated_at`이 같을 때만 저장, 다르면 서버본 다시 불러오기
- 소켓 실시간 동기화 안 함

## 근거

- 혼자 편집이 기본 - 공동 편집 계획 없음
- 방 통째 저장 구조에 그대로 붙음 - 병합·상주 연결 불필요

## 대안

| 대안             | 기각 이유             |
| ---------------- | --------------------- |
| 마지막 저장 우선 | 다른 곳 저장을 덮어씀 |
| 소켓 + 병합      | 공동 편집 없는데 비쌈 |
| Realtime 알림    | 저장 시점 감지로 충분 |

## 트레이드오프

- 저장할 때만 감지, 충돌 시 내 편집 버림
- 공동 편집이 생기면 다시 검토
