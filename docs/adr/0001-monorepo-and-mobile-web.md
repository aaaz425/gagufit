# 0001 모노레포 + 모바일 웹 1차 지원

2026-11-05 확정

## 결정

- 앱은 Expo WebView로 모바일 웹을 띄움
- 따라서 모바일 웹을 1차부터 데스크톱과 같은 기능으로 구현
- 웹·앱 공용 코드는 모노레포 패키지(core, api)로 분리

## 근거

- 앱이 모바일 웹을 그대로 씀 - 모바일을 미루면 편집기 재작업
- 앱도 core·api 사용 - 레포를 나누면 코드 중복

## 대안

| 대안                     | 기각 이유                 |
| ------------------------ | ------------------------- |
| React Native 네이티브 3D | 웹·앱 편집기를 따로 구현  |
| 단일 Next.js 레포        | 앱 추가 시 공용 코드 분리 |

## 트레이드오프

- 1차 범위 증가 - 터치 조작, 저사양 품질 설정
- WebView 3D 성능이 네이티브보다 낮음 - 품질 설정으로 대응
