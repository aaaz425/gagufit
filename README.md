# gagufit

3D 방 배치 시뮬레이터 - [gagufit.com](https://gagufit.com)

## 시작

Node 22, pnpm 11 필요

```bash
pnpm install
pnpm dev
```

## 명령어

| 명령어           | 내용          |
| ---------------- | ------------- |
| `pnpm dev`       | 개발 서버     |
| `pnpm build`     | 빌드          |
| `pnpm lint`      | ESLint        |
| `pnpm typecheck` | 타입 검사     |
| `pnpm test`      | 테스트        |
| `pnpm format`    | Prettier 적용 |

작업 규칙은 [AGENTS.md](./AGENTS.md)
